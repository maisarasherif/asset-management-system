# Asset Management System (AMS)

Asset Management System with certification tracking and expiry alerts built with Go, Gin framework, and PostgreSQL.

## Features

- User authentication with http-only cookies.
- Role-based access control (ADMIN/USER/CLIENT)
- Asset management with categories
- Component tracking for each asset
- Certificate management with expiry tracking
- Email & ClickUp alerts for expiring certificates
- RESTful API architecture
