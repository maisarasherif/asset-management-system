# AMS Regression Suite

This folder keeps the maintained regression assets together:

- `api/` contains Newman/Postman API collections.
- `e2e/` contains Playwright browser/API specs.
- `fixtures/` contains files used by regression collections.
- `support/` contains local helper servers and targeted runner scripts.
- [TESTING_GUIDE.md](./TESTING_GUIDE.md) is the single authoritative guide for Go regression, Newman, and Playwright, including remote Fedora setup and local diagnosis.
- `ISOLATED_TESTING_GUIDE.md` and `FEDORA_STAGING_TESTING_GUIDE.md` are redirects kept for existing links.

Together they cover auth/session handling, user permissions, catalog/template CRUD, assets/components/certificates, uploads/reporting, routine maintenance, client portal access, single-asset equipment, admin/client-access screens, competencies, equipment types, scheduler audit APIs, HR/Admin product workflows, and whole-app route health.

Every new or changed feature must create or update its dedicated Go, Newman, and Playwright test files. Review/update the isolated runner for registration, fixtures, configuration, gates, and cleanup where applicable. Shared smoke suites supplement feature-specific coverage. See the authoritative guide for the feature-step testing and reporting requirements.
