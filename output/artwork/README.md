# Porto Marine A4 artwork

The SVG is the editable master, recreating the AMS login brand panel on an A4 portrait page (210 × 297 mm). The page proportions and spacing are adapted for A4; the original wording, colours, and vector logo are retained.

Open the SVG in Inkscape or Illustrator. Six named layers separate the background, grid, company/logo, headline/description, ISO certifications, and compliance badges. Text remains live and editable; the embedded original logo consists of editable paths. No linked images or external assets are required.

Fonts: Georgia Bold for the headline, Arial Regular/Bold/Italic for the other text. Install these fonts on the editing computer to preserve the layout. Keep this master with live text when making changes.

The companion PDF in `../pdf/porto-marine-login-panel-a4.pdf` is one A4 page with fonts embedded. It is an RGB PDF with no bleed or crop marks, not a press-certified PDF/X file. Print at 100% / actual size. For newspaper production, have the printer or designer prepare the final file using the publisher's required colour profile, ink limits, and bleed specifications. The navy background reaches the page edge; ordinary office printers may introduce white margins.

The preview PNG is for viewing only. Use the SVG or PDF for production. Certification and membership wording is copied from the login page.
